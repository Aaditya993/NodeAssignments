# Node.js File System Assignment

## Assignment Explanation
This project demonstrates the core capabilities of the Node.js `fs` (File System) module by performing sequential CRUD (Create, Read, Update, Delete) operations. 
* **Task 1:** Creates a file named `student.txt` using `fs.writeFile()`.
* **Task 2:** Reads the contents of the newly created file using `fs.readFile()` and logs it to the terminal.
* **Task 3:** Appends new data to the existing file without overwriting it using `fs.appendFile()`.
* **Task 4:** Renames the file to `studentDetails.txt` using `fs.rename()`.
* **Task 5:** Deletes the final file using `fs.unlink()`.

## How to Run the Program
1. Ensure Node.js is installed on your machine.
2. Open the terminal and navigate to the project directory.
3. Run the following command:
   \`node index.js\`
